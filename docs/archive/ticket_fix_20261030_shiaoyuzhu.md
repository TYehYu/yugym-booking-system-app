# 蕭育筑 #24 自訂方案 帳本更正（2026-10-30）

使用者問：「這堂打勾的是怎麼產生的」（票券卡上第一格是沒有日期的 ✓）

## 那個 ✓ 是什麼

**帳本扣掉了，但畫面配不到是哪一堂。** 畫圓圈時用的是「綁這張票＋已完成」的課；
餘額 0 → 8 格都要畫成已用，但只配得到 7 個日期，第 8 格就變成沒有日期的 ✓。

| | 原本 |
|---|---|
| 帳本扣了 8 堂 | 8/29、9/5、9/12、9/19、10/3、**11/20、11/27、12/04** |
| 綁票且已完成 7 堂 | 8/29、9/5、9/12、9/19、10/3、**10/10、10/17** |

## 怎麼造成的

1. **10/07 13:28** 建立 11/20、11/27、12/04（**週五 16:00** 系列），各從這張票扣一堂。
   那一系列本來吃友善優惠1V1（TK-mu6o0s7fxdd4，8 堂），但它當時已經扣完 → 溢扣到這張。
2. **10/08 13:50** 用〔調課〕把 10/10、10/17 搬到這張票。
   〔調課〕的規則就是「**只搬 ticket_id、不重扣**」（見 memory/yugym-bk-move-ticket）。
3. 結果：那三堂未來的課把 ticket_id 讓了出去，帳本的扣款卻留著 → 兩邊對不起來。

⚠ 根本問題是**扣錯票**：自訂方案是「週六 14:00」那一系列的票，
11/20 那三堂是「週五 16:00」的課。

# 跑步機同行預約取消補強

狀態：發布前驗證完成，使用者已授權安全通過後正式套用與發布。正式庫套用與後置核對已通過；前端部署結果以交付回報為準。

會員取消自主訓練主預約時，原函式只退主卡的點數、取消主卡，留下免費同行跑步機占位。
修正版維持原權限及退點規則，先鎖主卡、依 id 鎖同行卡，再處理退點。
有效同行卡同步取消，不另外退點。重送不重退；已取消主卡重送可清理其有效同行卡，但不補退點。
會員不能單獨取消同行卡。同行卡的會員、課程、時間、場地、綁票或簽到狀態不符時整批停止。
任何資料庫例外都由原函式 exception 子交易回滾，包含先取消同行、後退點失敗的情況。

## 範圍

只修改 fn_cancel_booking(text,text,boolean) 的跑步機自主訓練取消分支；桌機與手機會員共用。
不變更歷史資料、不改其他購票／教練課／團課規則、不掃描或批次取消舊卡。
不修改既有函式的 PUBLIC execute 權限，權限收緊屬其他工作。
會員直接改期函式既有的同行同步搬移保持不動。
另新增 fn_treadmill_sibling_parent_guard 與觸發器，同行卡新增或恢復有效時鎖定主卡；主卡已取消就拒絕。取消同行卡本身跳過此鎖，避免正常取消流程逆向鎖定。新函式只供觸發器使用，沒有對外執行權限。

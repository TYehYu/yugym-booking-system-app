## 事故處理

- 前端尚未上線，且沒有新版收款／送簽：依另行授權用 unused rollback。
- 已有新版收款或送簽：保留收據、簽署紀錄與函式。不能直接刪除或退回舊收費路徑；先暫停該收費入口、查明狀態，提出局部修復。不能把重試改成新收據來規避。

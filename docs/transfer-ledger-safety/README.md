# 調課扣課歸屬保護：發布版 261120.2347

此版基於正式版 de2bd8c，經使用者「安全就推」條件授權。資料個案修復與本版程式補強分開；本版不批次變更會員、預約或票券餘額。

## 改動

現行調課 RPC 本來就同交易搬綁票與成對扣退堂。本次補強歷史孤兒扣堂與舊頁面直寫的防線，沒有另造第二套調課流程：

- 私人教練／運動按摩的淨扣堂為正時，內部檢查確認這筆預約仍綁在同張票；不一致回 TICKET.LEDGER_OWNERSHIP，不能誤退或把孤兒扣堂當作轉正成功。團課座位、自主訓練多點口徑不變。
- 新增交易結束時的綁票 UPDATE 守門：原票淨扣必須移出，新票淨扣必須存在。正常同交易成對搬帳可通過，只搬綁票沒搬帳的舊頁面會被拒絕。不掃描改寫歷史資料，不涵蓋 INSERT、DELETE、未改綁票或維運連線。
- 調課成功前再核對原預約淨扣 0、新預約淨扣 1、票券餘額不變；恢復呼叫前的窗口設定。
- 前端「已扣過」捷徑核對最新預約，讀取失敗就停止。櫃檯取消遇到孤兒帳會明確回帳務拒絕，不讓人以為網路錯誤而一直重按。

修改 4 支既有函式與新增 1 支內部觸發器函式；沒有新公開 RPC。既有執行權限全部保留，含櫃檯取消原有的 service_role 執行權；其內部仍需員工身分檢查。新 guard 與 net helper 不對一般 API 角色開放。

## 驗證完成

- SQL 假資料 44 項通過：hold／cancel、取消原課不退移走的堂數、取消新課只退一次、重新轉正確實再扣一堂、已簽到紀錄不受影響、共享票、團課相容、舊直寫拒絕、故障全回滾、權限與回復。
- 真實 HTTP 44 項通過，完整原報告見 evidence/HTTP_ACCEPTANCE_REPORT_ORIGINAL.json。R1 調課與取消原課、R2 調課與取消新課、R3 搶同一堂、R4 取消先到後調課，都有不同 pid、精確等待持鎖者 txid、案例標記與完成順序證據，所有並行請求 HTTP 200。
- 真實登入：1280 桌機及 390 手機，櫃檯／教練共 4 組，實際開調課視窗並點確認；每組來源淨扣 0、目標淨扣 1、餘額 3。以本機假資料快捷鈕開真正視窗，沒有替換視窗或寫入邏輯；不是完整行事曆導航驗收。會員直接呼叫員工調課遭拒。
- 共用前端函式 103 項、執行器失敗路徑 31 項、沿用 harness 64 項、精簡建置 23 項通過。相關 19 個舊測試檔 16 個通過；另 3 個失敗輸出與未修改基底完全相同，見 REGRESSION_SUMMARY.json。未處理既有失敗。
- 正式 apply／verify／rollback 的演練版在測試庫整檔實跑、含真 commit。演練版只機械替換叢集識別。第一次 apply 被 PRE.PIN 拒絕，原因是回復候選漏保留櫃檯取消原有 service_role 權限；已修正並整檔重跑，沒有放寬守門。
- 執行器先 bookings 再清 booking_op_rev，獨立查證測試殘留全 0。測試庫已拆除所有暫裝，函式、觸發器、欄位、權限、政策、索引、資料、Auth 皆回基準，登入 session 檔已刪，本機測試站已停。

## 正式套用與回復

正式 apply 已在單一交易提交並通過後置唯讀核對，見 evidence/PRODUCTION_POST_VERIFY.json。交易內核對其餘函式、觸發器、欄位、政策、表權限與業務逐列雜湊不變。既有安全顧問警示數未增加；這不代表整個系統沒有其他既有問題。

apply_prod.sql／rollback_prod.sql 都釘環境、精確函式本體、權限、owner、固定 search_path 與新 trigger 定義。任一不符整體回滾。verify_readonly.sql 是 SELECT。

前端可單獨退版並保留資料庫防線。資料庫若需回復須先審查事故原因與當下指紋，再執行已演練的 rollback_prod.sql；它回復函式與新 guard，不逆轉已完成的調課或已修復的會員資料。本檔記錄發布內容與發布前核對；實際前端部署結果以此提交的 GitHub Pages 流水線和線上版本核對為準。

## 重現

build_candidates.py 生成候選與回復；build_test.py／build_rollback_rehearsal.py 生成只限測試庫、整段 rollback 的假資料測試。build_acceptance_environment.py 生成受控 HTTP 環境，run_acceptance.cjs 沿用已驗證的追蹤、恢復與清除層，額外補齊 partial-write 保護，金鑰只隱藏輸入且不寫檔。build_release.py 生成正式階段檔。大型生成 SQL 與原始測試輸出只留本機，未進版控；來源與原始 HTTP 證據保留以供重現。
